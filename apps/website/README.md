# Auth website

The user-facing website for the Auth packages. It provides an introduction to
the library, documentation for every package and provider, and live
authentication examples.

Visit [auth.nicholasgriffin.dev](https://auth.nicholasgriffin.dev).

```sh
pnpm --filter @ngriffin_uk/auth-website dev
pnpm --filter @ngriffin_uk/auth-website build
pnpm --filter @ngriffin_uk/auth-website check
```
